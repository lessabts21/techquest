# TechQuest — Descubra seu talento tech

Aplicação educativa, gratuita e sem cadastro para jovens de 12 a 16 anos explorarem interesses em tecnologia.

## Como publicar no GitHub Pages
1. Crie um repositório público no GitHub (por exemplo `techquest`).
2. Envie `index.html`, `README.md` e `LICENSE` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O endereço ficará parecido com `https://SEU-USUARIO.github.io/techquest/`.

## Tecnologias
- HTML, CSS e JavaScript puro.
- Não precisa de servidor, banco de dados, Node.js ou instalação.
- Funciona como site estático e pode ser hospedado gratuitamente no GitHub Pages.
- A fonte DM Sans / Space Grotesk é carregada do Google Fonts; se estiver offline, o navegador usa fontes alternativas.

## Sobre o teste
O questionário tem 15 situações e cinco dimensões de interesse: Criar, Lógica, Explorar, Conectar e Proteger. A pontuação é usada para sugerir trilhas e atividades de exploração. É uma dinâmica educativa inspirada em abordagens de exploração de interesses, não um teste psicológico ou instrumento validado de orientação vocacional.

## Privacidade
As respostas são processadas localmente no navegador e não são enviadas a nenhum servidor. Não há cadastro, cookies próprios ou coleta de dados pessoais.

## Personalização
Edite `questions` e `dimensions` no final de `index.html` para alterar perguntas, perfis, áreas sugeridas e desafios.
